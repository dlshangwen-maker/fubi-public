# 《逻辑哲学论》可读版翻译要求（2026-10-20，用户：以可读性为准）

读者是愿意读哲学、但没有专业训练的普通人。要让他**一读就顺**，而不是像在读外语。

## 原则

1. **意思准确，表达自然**。以德文为准、英文参照，意思不能错；但句子按中文的习惯组织，不跟着德文语序走。
2. **长句拆短**。一个德文长句可以拆成两三句中文。少用"的……的……的"串联。
3. **避免翻译腔**：少用"被""所""之""对于……而言""这一点"；不用文言虚词（乃、亦、即、诸、皆、之所）。
4. **可以补最少的字让句子成立**（主语、连接词），但**不加解释、不加注**——解释是解释卡片的事。
5. 原文短而有力的地方（1、7、6.4311、6.54 这类）保持短而有力。
6. 独立翻译：不要背出现成译本的句子。但不必刻意求异——好懂最重要。

## 格式

- 编号不变；命题内原文分段的用 \n。
- 公式图片标记 ⟦img:…⟧ 原样放在原位置（见 公式图片.json）；逻辑记号照原样（p、q、ξ、N(ξ̄)）。表格用 ⟦表:…⟧ 标记，沿用现在译文里的写法。
- 引号用“”。JSON 字符串内不要用英文双引号。

## 好坏对照（现在的译文 → 可读版的方向）

- 1.11 现在：世界由事实所决定，并且由这些就是全部事实这一点所决定。
  → 方向：世界由事实决定，也由“这些就是全部事实”这一点决定。
- 2.0211 现在：如果世界没有实体，那么一个命题有没有意义，就要看另一个命题是不是真的。（这条已经可以）
- 4.0031 现在：一切哲学都是“语言批判”。（但并非毛特纳所说的那种意义。）罗素有一项功劳：他表明了，一个命题看上去具有的逻辑形式，未必就是它实际具有的逻辑形式。
  → 方向：全部哲学都是“语言批判”（不过不是毛特纳那种意义上的）。罗素的功劳在于指出：一个命题表面的逻辑形式，不一定就是它真正的逻辑形式。
