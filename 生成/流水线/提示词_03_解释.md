# 第 3 步：解释卡片（小说版 · 《红楼梦》）

每回一批。输入：这一回带编号的原文 + **截至这一回为止**的人物、概念索引（`上下文_第N回.json`，只含 ≤ 本回的信息）+ 前几回的事件提要。

---

你在为一个手机阅读器预先写解释卡片。读者第一次读程乙本《红楼梦》。读者点开第 X 段时，他刚好读完第 X 段，**没有读过 X 之后的任何内容**。

先读不剧透规则：`生成/流水线/规则_小说.txt`（{POS} 就是每一段自己的编号）。这些规则比下面所有要求都优先。

## 每段写三档

- **入门**：给第一次读古典小说的普通人。大白话，重点是"这段在说什么、这个人是谁、和谁什么关系"，难字难词顺手解释。
- **标准**：给愿意细读的读者。加上典故、诗词的意思、谐音、称谓礼制。
- **深入**：给想读出门道的读者。写法和结构（如真假、虚实）、古代的礼制和生活细节、诗词格律。**依然不能涉及后文**，也不引脂批和红学关于后文的说法。

## 每档三个字段

- `白话`：一句话说这段在讲什么。不超过 50 字。
- `展开`：2～4 句。人物关系、为什么这样写、一个帮助理解的说明。不超过 160 字（深入档可到 220 字）。
- `前置`：读懂这段需要的背景（称谓、礼制、典故等通用知识）。不需要就写 ""。不超过 100 字。

## 人物怎么写

- 只用上下文索引里**"从"不晚于当前段**的身份和别称。
- 某个人物在当前段之前还没出现，就不能提。
- 不说任何人物后来怎样。

## 诗词、判词、曲子（第一回的诗、第三回的西江月、第四回的护官符、第五回的判词和红楼梦曲）

- 只讲字面、字词、典故、格律，把句子讲顺。
- **绝对不说这首写的是谁**，即使谐音拆字一看就知道（如"二木""凡鸟""玉带林中挂"）。
- 可以加一句："这些判词和曲子，作者在后文会一一呼应，读到时可以回来对照。"（同一回里不要每张卡都重复，第一次出现时说一次即可。）
- 曲名单独成段的（如"终身误"），写一张很短的卡片：曲名的字面意思即可。

## 回末一句（"且听下回分解"之类）

写一张很短的卡片，说明这是章回小说的固定收尾即可，**不要**预告下回内容。

## 质量

- 准确第一，拿不准宁可少说。
- 三档要真的不同。
- 很短的过渡段，可以短，但三档都写。

## 输出

一个 JSON 对象，键是段号（如 "3.12"），值是：

```json
{
  "入门": {"白话": "...", "展开": "...", "前置": ""},
  "标准": {"白话": "...", "展开": "...", "前置": "..."},
  "深入": {"白话": "...", "展开": "...", "前置": "..."}
}
```

这一回的每一段都要有。JSON 字符串内部不要用英文双引号，需要引号时用“”或「」。
