# 第 3 步：解释卡片（现代小说版，也用于短篇集）

> 短篇集（如《呐喊》）：规则换成 `规则_短篇集.txt`；"章"即"篇"，读者读的是这一篇，当作没读过其他篇。

（第一次用于《三体 I》，2026-10-19。和红楼梦版的区别：按"解释单元"写，不按段；规则换成 `规则_现代小说.txt`；没有诗词判词，多了科学/虚构名词。）

输入：这一章按解释单元分组的原文（`第00N章_单元.txt`）+ 截至本章的上下文（`上下文_第00N章.json`）+ 不剧透规则。

---

你在为一个手机阅读器预先写解释卡片。读者第一次读《{书名}》。读者点开某个单元时，他刚好读完这个单元的最后一段，**没有读过之后的任何内容**。

先读不剧透规则 `规则_现代小说.txt`（{POS} 就是这个单元最后一段的编号）。规则比下面所有要求都优先。

## 每个单元写三档

- **入门**：给不常读科幻、不熟悉科学的普通读者。大白话：这几段发生了什么、出现的人是谁、和谁什么关系；难懂的科学名词顺手用一句话讲清。
- **标准**：给愿意细读的读者。科学概念讲准确一点；人物的处境和心理；这几段的写法（视角、节奏）。
- **深入**：给想读出门道的读者。科学背景讲到位（真实的物理学、天文学、历史）；叙事手法；和已读部分的呼应。**依然不能涉及后文**，不能借科学知识暗示情节。

## 每档三个字段

- `白话`：一句话说这个单元在讲什么。不超过 50 字。
- `展开`：2～4 句。不超过 160 字（深入档可到 220 字）。
- `前置`：读懂需要的背景（科学名词、历史背景、真实人物）。不需要就写 ""。不超过 100 字。

## 人物怎么写

- 只用上下文里"从"不晚于本单元最后一段的身份和别称。
- 名字还没出现的人，用当时书里的叫法（例如名字出现之前，只能叫"那个便衣"）。
- 不说任何人物后来怎样、"其实是谁"。人物的动机书里没交代的，不猜。

## 谜团怎么写

- 书里刻意没解释的现象、名词、游戏、人物的话：只复述书里目前交代的，可以说"书里还没有解释"。
- 不挑出某个细节说"值得注意"——强调本身就是提示。
- 科学知识可以讲，但只讲科学本身。例如：讲宇宙背景辐射是什么、怎么测量，可以；说"如果背景辐射真的闪烁，意味着……"去推测情节，不行。

## 质量

- 准确第一，拿不准宁可少说。科学内容要正确。
- 三档要真的不同，不要只是字数不同。
- 很短的过渡单元可以短，但三档都写。

## 输出

一个 JSON 对象，键是单元第一段的编号（如 "3.12"），值是：

```json
{
  "入门": {"白话": "...", "展开": "...", "前置": ""},
  "标准": {"白话": "...", "展开": "...", "前置": "..."},
  "深入": {"白话": "...", "展开": "...", "前置": "..."}
}
```

这一章的每个单元都要有。JSON 字符串内部不要用英文双引号，需要引号时用“”或「」。
