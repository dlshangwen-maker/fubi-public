# 提示词 06：读书小结（导出读书笔记时生成）

2026-10-19 · 用户定的方向：小结的核心是**整体的读书感悟**——根据读者的阅读行为，替读者说出他心里有、但一时不知道怎么表述的那层感受。说中了，读者会觉得"这正是我想说的"，从而对这本书、对这个应用产生好感。

---

## 一、输入

```json
{
  "书": "《红楼梦》",
  "读到": "第五回（共读 5 回，demo 全部）",
  "已读原文": "……（第一回到读到位置为止的全文，带段号）",
  "记录": {
    "划线": [{"位置": "4.17", "原文": "雨村便徇情枉法，胡乱判断了此案", "想法": "原来不是心高，是心冷。", "时间": "…"}],
    "提问": [{"位置": "2.16", "问题": "心机又极深细，是夸还是贬？", "结果": "当场回答 / 埋为伏笔 / 已回收"}],
    "伏笔": [{"来源": "书里埋的", "位置": "1.29", "问题": "…", "猜想": "心高气傲，不愿受人恩惠", "把握": 6, "后来": "在第二回回收", "回收说明": "…"}],
    "书签": ["3.11"],
    "行为": {
      "人物卡打开次数": {"王熙凤": 4, "贾雨村": 3},
      "解释深浅切换": [{"位置": "5.23", "从": "标准", "到": "深入"}],
      "停留较久的段落": ["5.23", "5.53"],
      "阅读天数": 4
    }
  }
}
```

只用这两样作依据：**读者的记录**、**读者读过的原文**。不用模型对全书的记忆。

---

## 二、输出：三段

### 1. 感悟（主体，200～350 字）

- **用读者的口吻（第一人称"我"）写**，像读者自己写下的读后感。顶部标明"以你的口吻写成，可直接修改"。
- 先找出记录里**反复出现的关注点**：划线集中在谁、什么事；想法里重复的词和情绪；在哪里停得久、问得多、切到了"深入"；哪些人物卡反复打开。
- 把这些散点**连成一条读者自己可能还没说出口的线**。这是这一段的价值所在：读者写的是零碎的句子，小结要说出把它们串起来的那层意思。
  - 例：读者分别写过"雨村是心冷""凤姐是夸还是贬"——可以连成"我一直在看人怎么变，看一个人说的话和他做的事怎么对不上"。
- **每一个判断都要能在记录里找到依据**；推进可以比读者多走一步，但方向必须是读者自己的。读者的原话可以化进句子里，引号内必须一字不差。
- 写具体的人、事、句子，不写空泛的套话（"这部伟大的作品让我感受到人性的复杂"之类一律不用）。
- 可以有情绪，但只写记录里看得出的情绪；**不编造读者的个人经历**（不写"我想起了外婆"）。
- 读者有疑惑、没读懂的地方，如实写成疑惑，不替他假装读懂了。

### 2. 这一程的线索（3～5 条，每条一行）

事实性的回顾，给感悟做注脚：
- 划线和想法最集中的地方；
- 当时的猜想（几成把握）与原文后来的写法，**并排放，不评对错**；
- 还挂着的问题。

### 3. 接着想（1 个问题）

从读者自己的笔记里引出，指向**已读**的某一处原文，让他回去再读一遍。不指向后文。

---

## 三、红线

1. **不越过阅读进度。** 不提未读的情节、人物、结局；不暗示"后面会……"。判词、伏笔只按已读部分说，不对号入座。
2. **不替人读。** 不写书的梗概、主题总结、文学评论；写的是"我这样读"，不是"这本书讲了什么"。
3. **不评判。** 不说"猜对了 / 猜错了"，不夸"很敏锐""读得很细"，也不打分、不比较。
4. **引用一字不差**，并能对应到记录或原文的位置。
5. **记录太少不生成**：划线 + 想法 + 提问 + 猜想合计少于 5 条，或想法少于 1 条时，不生成感悟，只给"线索"，并提示"记录再多一些，可以生成读后感"。
6. **敏感内容**：读者的想法里如果流露出明显的情绪困扰，不放大、不分析，感悟只写与书有关的部分。
7. 语气平静、书面，不用感叹号，不用网络流行语。

---

## 四、示例

依据的记录（假设）：9 条划线，其中 5 条与贾雨村有关；想法 3 条——4.17"原来不是心高，是心冷。"、2.16"是夸还是贬？"、1.41"士隐走得这么干脆。"；伏笔 1.29 猜"心高气傲，不愿受人恩惠"，6 成把握；王熙凤的人物卡打开 4 次；第五回判词段落 6 次切到"深入"；还挂着"还泪""玉带林中挂"两处伏笔。

> **感悟**（以你的口吻写成，可直接修改）
>
> 读到第五回，我发现自己一直在看人怎么变。第一回贾雨村拿了银子不辞而别，我还当他是心高气傲；到第四回他照着门子的主意把案子胡乱判了，又把门子远远打发走，我才明白，他心里记着的不是恩情，是自己的来路。我在那里写下"原来不是心高，是心冷"。回头再看甄士隐，一个在葫芦庙旁资助了他，最后两手空空跟着道人走了，走得那样干脆；一个从葫芦庙出发，一路往上走。同一座庙前，两个人去了相反的方向。
>
> 王熙凤也是这样。她还没出场，冷子兴就说她"心机又极深细"，我当时不知道这算夸还是贬。等她笑着进门、一转眼又为姑妈落泪，我好像懂了一点：在这个家里，会说话本身就是一种本事。
>
> 第五回的判词我大多读不懂，却一首首调到"深入"去看。也许我要的不是现在就知道答案，而是先把这些句子记下来，等书里的人一个个走到它们面前。
>
> **这一程的线索**
> - 划线最多的是贾雨村：赠银、不辞而别、徇情判案。
> - 第一回猜他"心高气傲，不愿受人恩惠"（6 成把握）；第二回原文写他"貌似有才，性实狡猾"。
> - 王熙凤的人物卡打开了 4 次。
> - 还挂着两处：绛珠草怎样还泪；"玉带林中挂，金簪雪里埋"说的是谁。
>
> **接着想**
> 你说雨村是"心冷"。第二回智通寺那副对联——"身后有余忘缩手，眼前无路想回头"——放在他身上读，是什么意思？
>
> AI 整理 · 依据你的划线、想法、猜想和阅读记录 · 可编辑

## 五、接入说明（有 API 密钥之后）

- 读者在"笔记 › 导出读书笔记"点"生成读后感"时调用；生成结果放在导出文件最前面，下面是原样的记录。
- 生成后过一遍事后剧透扫描（`spoiler_scan.py` 的规则：未出场人名、未读概念、暗示字眼）。
- 读者编辑过的版本以读者为准，再次生成不覆盖，另存一版。
- 需要的行为数据里，"人物卡打开次数""解释深浅切换"已经在 demo 里记录；"停留较久的段落"还没有记。
