# 第 2 步：按章抽取索引（人物 / 概念 / 事件）· 通用版

（由红楼梦版 `提示词_02_索引.md` 改写，不限定书名和"回"。）

---

你在为一个"不剧透"的阅读器建索引。下面是《{书名}》第 {N} 章（短篇集里叫"篇"，编号"篇.段"）的全文，每段前面有编号（章.段）。

**只根据这一章的原文抽取，不要用你对全书的了解补充任何这一章没写的信息。** 这一点最重要：你可能读过这本书，知道很多人物后来的事，但索引里只能写这一章书上写了的东西。

请输出一个 JSON 对象，三个键：

## 1. "人物"

这一章里出现的每一个人物（包括只被提到名字、没有出场的）。每个人物：

```json
{
  "名": "汪淼",                    // 最通行的全名；只有称呼没有名字的，用书里的称呼（如"那个便衣"）
  "这章的叫法": ["汪淼", "汪教授"],  // 这一章原文里实际出现过的所有称呼，逐字照抄
  "首次": "1.1",                   // 这一章里第一次出现（含被提及）的段号
  "出场": "1.1",                   // 第一次本人出场的段号；本章没出场就写 ""
  "身份": [                         // 按交代的先后分条，每条写清"从"哪一段起读者才知道
    {"从": "1.1", "写": "被两名警察和两名军人找上门的人"},
    {"从": "1.9", "写": "纳米材料研究中心的研究员"}
  ],
  "关系": [["史强", "初次见面的警察", "1.3"]],   // [对方, 关系, 从哪一段交代]
  "这章做了什么": "一两句",
  "备注": ""                        // 例如"真实历史人物""名字到某段才出现，之前只叫某称呼"
}
```

注意：
- **身份必须按段截断**：同一章后面才交代的事，不能写进前面那条的"从"里。宁可多分几条。
- 名字在某段之后才出现、之前只用称呼的（"那个便衣"→"史强"），在备注里写明名字第一次出现的段。
- 一个人有多种叫法，合并成一条；拿不准是不是同一人，分开列并写备注。
- **没有名字的人，称呼用原文里指这个人的名词**（侦探、车夫、老女人），不要用动作或"……的"（如"绑着的""做老子的"——这是描述，不是称呼）。"名"也照此写。
- 群体不列；书中被引用的真实人物（科学家、历史人物）列出，备注"真实人物"。

## 2. "概念"

这一章里需要解释的词：科学名词、书中虚构的名词/组织/技术、历史事件、地名、专业术语、不常见的说法。每个：

```json
{"词": "纳米材料", "首次": "1.9", "说明": "只写通用含义，或这一章原文给出的含义", "虚构": false}
```

`虚构`：书中虚构的名词写 true（这类词的说明只能用本章原文）。每章 10～30 个。

## 3. "事件"

这一章按顺序发生的事，每件一句话，带段号：

```json
{"段": "1.12", "事": "……"}
```

只记事实，不评价，不解读。每章 8～20 件。

---

只输出 JSON，不要其他文字。JSON 字符串内部不要用英文双引号，需要引号时用“”。
