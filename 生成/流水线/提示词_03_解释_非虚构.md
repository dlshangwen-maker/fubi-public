# 第 4 步：解释卡片（非虚构版：传记、历史、纪实、论说）

（第一次用于梁启超《李鸿章传》，2026-10-22。和小说版的区别：规则换成 `规则_非虚构.txt`；重点是读懂文言/旧白话、历史背景和作者的论证；段落有类型标记。）

输入：这一章按解释单元分组的原文（`第00N章_单元.txt`）+ 截至本章的上下文（`上下文_第00N章.json`）+ 不剧透规则。

---

你在为一个手机阅读器预先写解释卡片。读者第一次读《{书名}》。读者点开某个单元时，他刚好读完这个单元的最后一段，**没有读过之后的任何内容**。

先读不剧透规则 `规则_非虚构.txt`（{POS} 就是这个单元最后一段的编号）。规则比下面所有要求都优先。

## 每个单元写三档

- **入门**：给读不惯文言、不熟悉这段历史的普通读者。先用大白话把这几段**说了什么**讲明白（必要时近乎逐句翻译要点）；出现的人是谁（一句话）；难懂的词顺手解释。
- **标准**：给愿意细读的读者。作者在这里的论点和理由；相关的历史背景（制度、事件的来龙去脉）；作者用了什么比较、举了什么例子。
- **深入**：给想读出门道的读者。作者的写法（夹叙夹议、对比、反问）；这段论述和已读部分的呼应；当时的写作处境（作者与书中人的关系、写作时间）。**依然不能涉及后文**——不能提作者后面才下的结论，不能讲书里后面才写的经过。

## 每档三个字段

- `白话`：一句话说这个单元在讲什么。不超过 50 字。
- `展开`：2～4 句。不超过 160 字（深入档可到 220 字）。
- `前置`：读懂需要的背景（官制、事件、人物、典故）。不需要就写 ""。不超过 100 字。

## 按段落类型

单元原文里每段前可能有标记：
- 【提要】章首的小节列表：三档都很短，只说本章分几部分、各是什么方面。
- 【文件·默认折叠】整份条约、奏折、报告、他人文章（阅读器里默认折叠）：说明这是什么文件、作者为什么全文收录（只用作者在前文自己说过的理由）、最要紧的几条用白话讲；不逐条复述。
- 【引文】短引文、表格、诗、对联：讲意思；表格（写作 ⟦表:…⟧）说明各栏是什么、看出什么（只说表本身显示的）。

## 人物怎么写

- 都是真实人物，可以用通用历史常识介绍身份（一句话，够读懂这一段即可）。
- 他们在**这本书里**做了什么，只写到当前位置为止书里写了的。
- 作者对人物的评价要说成"作者认为……"。

## 质量

- 准确第一，拿不准宁可少说。历史年代、官名、人名要对。
- 三档要真的不同，不要只是字数不同。入门档最重要：读者能不能读懂，主要靠它。

## 输出

一个 JSON 对象，键是单元第一段的编号（如 "3.12"），值是：

```json
{
  "入门": {"白话": "...", "展开": "...", "前置": ""},
  "标准": {"白话": "...", "展开": "...", "前置": "..."},
  "深入": {"白话": "...", "展开": "...", "前置": "..."}
}
```

这一章的每个单元都要有。JSON 字符串内部不要用英文双引号，需要引号时用“”或「」。
