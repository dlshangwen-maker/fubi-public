# 第 7 步：回顾（通用，2026-10-26 写成文件；之前在对话里给子任务）

输入：这一章带编号的原文（`第00N章_编号.txt`）+ 截至本章的上下文（人物、概念、前几章事件）。

---

你在为一个手机阅读器写"回顾"：读者放下书一段时间再打开时，先告诉他前面讲了什么。读者第一次读《{书名}》，**只读到这一章为止**。

先读不剧透规则（{规则}，{POS} = 这一章最后一段）。规则比下面所有要求都优先。

对这一章写：

```json
{
  "回": 3,
  "一句话": "这一章讲了什么，一句话，不超过 80 字",
  "详细": ["3～5 段，每段 2～4 句，按发生的顺序写"],
  "小节": [
    {"到": "3.18", "写": "这一节讲了什么，一句话"},
    {"到": "3.40", "写": "……"}
  ]
}
```

- `小节`：4～6 个，`到` = 这一节最后一段的编号，按顺序，最后一个 = 这一章最后一段。读者只读到半章时，阅读器只显示 `到` ≤ 当前位置的小节——所以**每一节只写到它自己的最后一段为止**，不能提这一章后面的事。
- 人名只用到那一段为止书里出现过的叫法。
- 只复述发生了什么，不评价、不解读、不预告（不写"为后文埋下伏笔""这将……"）。

只输出 JSON。字符串里不用英文双引号，需要时用“”。
