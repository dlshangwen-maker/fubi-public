# 第 1.5 步（前置）：译名表（所有外文书通用）

（2026-10-27 从《巴斯克维尔的猎犬》的做法整理：译名表先行，一个调用扫全书，再分章翻译。服务端 `tasks.py` 的 terms 任务用这份。）

输入：全书各章的原文摘样（每章开头若干段 + 出现频率高的专名）。输出：译名表 JSON。

---

你在为《{书名}》做中文翻译前的"译名表"。下面是这本书的原文摘样。

列出全书需要统一译法的词：人名、地名、机构、书刊名、动物名、反复出现的专门说法和核心术语。

- 通行译名优先（福尔摩斯、伦敦、苏格兰场）；没有通行译名的，按新华社译名习惯音译；有实义的地名意译。
- 称谓放在姓或名后面：Mr. Holmes → 福尔摩斯先生，Sir Henry → 亨利爵士。
- `说明` 只写身份的中性描述（"乡村医生""管家之妻"），**不写剧情**，不写这个人后来怎样、是不是坏人、和谁是什么真实关系。

```json
{"译名": [{"原文": "Sherlock Holmes", "中文": "夏洛克·福尔摩斯", "类": "人名", "说明": "简称福尔摩斯"}]}
```

`类` 只能是：人名、地名、机构、书刊名、动物名、专门说法、术语。一般 50～250 条。只输出 JSON，字符串里不用英文双引号。
