# 第 1 步：文本（《红楼梦》）

输入：`原始资料/紅樓夢（程乙本）.epub`（维基文库，2026-10-16 下载）
输出：`文本数据/红楼梦/全文.json`、`文本数据/红楼梦/第001回.txt` … `第120回.txt`

## 怎么跑

```bash
mkdir -p /tmp/hlm_raw && cd /tmp/hlm_raw && unzip -o -q "<Read Book>/原始资料/紅樓夢（程乙本）.epub"
cd /tmp/hlm_work   # 把本目录 4 个脚本拷过来
python3 -I parse.py /tmp/hlm_raw trad.json   # 解析 EPUB → 120 回繁体
python3 -I convert.py                        # 繁转简 → simp.json
python3 -I structure.py                      # 分段编号、标诗词 → 写入 文本数据/红楼梦/
```

（convert.py / structure.py 里的路径是写死的，换书时要改。）

## 各脚本做什么

- `parse.py`：每回是一个 `<h2>`，后面的 `<p>` 是段落；跳过序、叙、引言；回目编号兼容"第一百回"和"第一○○回"两种写法。
- `t2s.py`：沙箱装不了 OpenCC，用系统自带的 ICU（libicu70）的 `Hant-Hans` 转换器。
- `convert.py`：**逐字**转换（整句转换时 ICU 会按词替换：察→查、甚么→什么、彷彿→仿佛，不符合原文），再用修正表处理一对多的字：
  - 乾隆、乾坤保留"乾"；
  - "著"统一为助词"着"，只有"著书立说"保留；
  - 底本里当"画"用的"劃"（忽劃一惡狼）改成"画"，筹划、划船保留"划"；
  - 维基文库的录入错误"巨集"→"宏"（"宽宏量"）。
- `structure.py`：
  - 段落编号"回.段"（如 `5.23`），全系统的坐标；
  - 判词和后面的叙述在同一段的（"……一梦遥。后面又画着……"），拆成两段；
  - 诗词按规则判断（整齐的 3～7 字分句、无对话引号），**前五回人工核对**：补上漏判的（好了歌注、护官符、红楼梦曲），曲名单独标 `"类型":"曲名"`。
