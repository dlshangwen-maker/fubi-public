# 第 1.5 步：翻译（可读版，所有外文公版书通用）

（2026-10-22 从 `生成/翻译/逻辑哲学论/可读版要求.md` 推广而来。用户 10-20 定：**可读性优先**。）

输入：
- `生成/翻译/<书>/输入/第NN章.json`：`[{"id":"3.12","en":"原文"}…]`（原文语言见配置，可能是 en/de/fr）
- `生成/翻译/<书>/译名表.json`：人名、地名、专名、核心术语的统一译名（先由一个子任务全书生成）

输出：`生成/翻译/<书>/译文/第NN章.json`：`{"3.12":"中文", …}`，每段一条，编号一一对应。

---

你在为一个手机阅读器翻译一本外文公版书。读者是普通中文读者，要让他**一读就顺**，像在读一本好的中文书，而不是在读外语。

## 原则

1. **意思准确，表达自然**。意思不能错、不增不减；句子按中文习惯组织，不跟着原文语序走。
2. **长句拆短**。一个长句可以拆成两三句。少用"的……的……的"串联。
3. **避免翻译腔**：少用"被""所""之""对于……而言""这一点"；不用文言虚词（乃、亦、即、诸、皆）。
4. 可以补最少的字让句子成立（主语、连接词），但**不加解释、不加注**——解释是解释卡片的事。
5. 原文短而有力的地方保持短而有力。小说的对话要像人说话，口吻贴合人物（福尔摩斯冷静利落，华生诚恳）。
6. **独立翻译**：不要背出现成中译本的句子；也不必刻意求异——好懂最重要。
7. **人名、地名、专名、术语严格按译名表**；表里没有的，按通行译法，同一个词全书一致，并在回报里列出你新定的译名。

## 格式

- 编号不变，一段对一段，不合并、不拆分段落。
- 引号用“”，引号里再引用用‘’。JSON 字符串里不要出现英文双引号 "。
- 原文的斜体强调可以用中文的着重语气表达，不加符号。
- 书信、电报、日记等原样保留格式（换行用 \n）。
- 数字、年份照原样（阿拉伯数字）；英制单位照译（英里、英尺），不换算。

## 自检

写完一章，用 python 检查：键集合 = 输入的 id 集合；每段非空；无英文双引号；中文引号成对；译文长度不低于原文英文字符数的 0.2 倍（英译中正常在 0.3 左右；太短可能漏译）。
