# 翻译：外文公版书 → 中文（流水线第 1.5 步，也是将来的后台服务）

2026-10-20 · 第一次用于《逻辑哲学论》（德文原著 + 英文译本 → 中文）。

## 为什么要有这一步

外文公版书的中译本大多还在版权期（译者也有版权）。我们自己从原文翻译，新译文没有版权问题。用户在伏笔里搜到或上传一本外文公版书时，后台自动跑这一步，读者可以选**只看中文 / 只看原文 / 对照**。

## 位置

在"第 1 步 文本"之后、"第 2 步 索引"之前。之后的索引、解释、伏笔都基于中文译文做，但每段都保留原文，阅读器可以切换。

## 输入、输出

- 输入：`生成/翻译/<书>/原文.json`——每段（或每条命题）的原文，可以有多种语言（如德文原著 + 英文旧译）。注明以哪种为准。
- 输出：`生成/翻译/<书>/译文.json`——同样的编号，每段一个 `zh`；`术语表.json`；`检查.json`。
- 阅读器数据里，每段同时带 `zh` 和原文（`de` / `en`），由阅读设置决定显示哪个。

## 步骤

1. **术语表先行**。全书的核心术语先定译名（每个术语一个中文，全书统一），写成 `术语表.json`：原文 → 中文 → 一句说明。术语表本身不受版权保护，可以沿用学界通行译名。所有翻译批次都带着术语表。
2. **按章分批翻译**（可以并行），每批带上：术语表、翻译要求、前后文（上一批最后几段的译文，保证文气连贯）。
3. **自动检查**（`check_translation.py`）：段数对齐、编号一致；每段非空；术语表里的原文术语出现时，译文里对应的中文是否出现；数字、公式符号、引号成对；长度比例异常（译文远短于原文，可能漏译）。
4. **模型抽查**：另开一个调用，随机抽 10% 对照原文看漏译、错译、术语不一致。
5. **（上线前）防雷同抽查**：名著已有不少中译本，模型翻译偶尔会和某个现有译本高度相似。上线前抽几段和常见译本比对，太像的改写。**翻译时不能给模型看任何现有中译本。**

## 翻译要求（写进提示词）

- 以指定的原文为准（逻辑哲学论：德文为准，英文参照理解）。
- 准确第一：不增不减，不解释，不意译成白话导读（解释是解释卡片的事）。
- 现代通顺的书面中文；原文简洁的地方译文也简洁。
- 术语严格按术语表；术语表没有的，同一个词全书用同一个译法，并记下来。
- 专名：通行译名优先（弗雷格、罗素），第一次出现不加原文。
- 公式、逻辑符号照原样保留（转成 Unicode）；表格用 `⟦表:单元格|单元格;下一行…⟧` 标记。
- 引号用中文引号“”。

## 作为后台服务的样子（以后）

用户导入一本外文书 → 识别语言和是否公版 → 自动生成术语表（模型）→ 分章并行翻译 → 自动检查 → 存入书库；书在翻译完成前就可以先看原文，翻完一章开放一章。翻译结果按书缓存，同一本书只翻一次，所有用户共用（这一点只对公版书成立；用户上传的非公版书只给他自己用）。

## 跑《逻辑哲学论》学到的（2026-10-20）

1. **分 4 批并行**（前言 + 1～3 / 4 / 5 / 6～7），每批 100～160 条，每批 3～7 分钟。各批自己会在术语表之外新定很多译法（每批 50～70 个），彼此有分歧（标示方式/标示法、阐释/阐明……）。**合并后要统一一遍**；以后可以先让一个子任务把全书的二级术语也列出来，再分批翻译。
2. **防雷同是真问题**：即使提示"不参考现有译本"，模型对名著的记忆仍会让译文和最通行的译本很像——初稿 526 条和贺译的相似度中位数 0.70，较长句里有 36 条 ≥0.85。短句、几乎全是术语的句子撞车无法避免，也不构成问题；**要处理的是较长、措辞特有的句子**。做法：`check_translation.py` 带上旧译算相似度 → 列出 ≥0.85 且 ≥25 字的 → 另开子任务从德文独立重译。
3. **防雷同重译会把文风带偏**：第一次重译为了"不一样"，用了大量文言虚词（之、乃、亦、诸），还出了误译（"几何之所"）。第二轮要求"和全书文风一致 + 准确 + 相似度 <0.75"才对。**重译提示里必须同时写文风和准确的要求**。
4. **旧译不只是正文**：解释卡片、伏笔、示范问答是照着旧译写的，引号里引了旧译原句，还有大量"贺译……""中译……"的评论和旧译术语（指谓）。换译本 = 正文 + 所有派生内容一起换，第二轮改了 485 个字段。以后的书从一开始就用自译本生成，就没有这个问题。
5. **原文里的 LaTeX**：古登堡的数学/逻辑书常是 LaTeX 源；`latex_clean.py` 能把大部分转成可读文本（下标上标转 Unicode），真值表等复杂排版只能粗略处理，旧数据里有图片的保留图片。

6. **（用户 2026-10-20 定）可读性优先**：第一版"准确 + 防雷同"的译文用户觉得不好读。改为按 `生成/翻译/逻辑哲学论/可读版要求.md` 重译：长句拆短、去翻译腔、术语向普通读者靠（函数而不是函项、自变量而不是主目、所指而不是指称），附"现在 → 可读版"的对照例子。防雷同不再刻意追求，只要求独立翻译、不背现成译本。**以后的书默认用可读版要求。**

## 跑《巴斯克维尔的猎犬》学到的（2026-10-22）

1. **译名表先行**（人名、地名、机构、书刊、狗名、反复出现的说法，214 条），一个子任务全书扫一遍；说明栏**不写剧情**（"斯台普顿一家"不写兄妹还是夫妇）。
2. **5 批并行**（每批 3 章、约 6 万英文字符），每批 4～11 分钟；每章写完立刻落盘。各批新定的译名在回报里列出，冲突很少。
3. 提示词通用化为 `提示词_01b_翻译_可读版.md`。长度自检阈值 0.35 太高（英译中正常 0.29～0.33），改为 0.2。
4. 原文一段话跨多个自然段时，只在最后一段收引号——照原文保留，引号不成对不算错。
